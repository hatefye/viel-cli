viel for Windows

Run viel-setup.exe. It installs viel to C:\Program Files\viel, adds it to the
Start menu, and offers a desktop shortcut on the last page. Uninstall from
Settings > Apps.

Windows SmartScreen warns the first time because the build is not signed:
choose "More info" and then "Run anyway".
Needs the Microsoft Edge WebView2 runtime, which Windows 11 and up-to-date
Windows 10 already have.

viel-windows.zip is the portable build: keep viel.exe and libmpv-2.dll in the
same folder and run viel.exe.
